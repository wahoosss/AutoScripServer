개인정보 처리방침

본 앱은 사용자의 휴대폰에서 사용자가 직접 만든 화면 자동화 스크립트를 실행하는 도구입니다. 「무료 + 광고」로 운영되므로 광고를 불러오기 위해 통신하며, 동의 후 필요한 실행 통계와 크래시 정보를 전송합니다. Google Play 를 통해 배포되며, 개인정보 보호는 Google Play 정책과 EU 일반 데이터 보호 규정(GDPR)을 따릅니다. 먼저 요약으로 핵심을 안내한 뒤 항목별로 설명합니다.

0. 30초 요약

  • 사용자가 만든 스크립트(탭 위치, 좌표, 텍스트, 시간, 반복 횟수, 스크립트 이름)는 기기에만 저장되며, 업로드되지 않고 광고 타기팅의 근거로도 사용되지 않습니다.
  • 본 앱은 Google AdMob 광고로 무료 운영을 유지하며, 광고에는 기기·네트워크·광고 식별자(GAID) 등의 정보가 사용됩니다.
  • 첫 실행 시 동의 또는 거부를 선택할 수 있습니다: 동의 = 개인화 광고 + 통계 활성화, 거부 = 비개인화 광고만 + 통계 미활성화. 어느 것을 선택하든 기기의 모든 기능은 그대로 사용할 수 있습니다.
  • 연락처, SMS, 통화 기록, 사진, 정확한 위치를 수집하지 않으며, 다른 앱에서 입력한 비밀번호나 결제 정보를 읽지 않습니다.

1. 동의를 얻는 방식

첫 실행 시 본 앱은 온보딩 마지막 화면에 본 방침을 전시하고 기본적으로 체크된 확인 상자를 제공합니다. 동의는 기본 상태가 아니라 사용자가 직접 「시작하기」를 누르는 행위로 판단됩니다:

  • 체크한 채로 「시작하기」를 누름 = 동의: 개인화 광고와 Google Firebase 분석을 활성화합니다;
  • 체크 해제 후 「시작하기」를 누름 = 거부: 분석을 활성화하지 않고 사용 및 크래시 데이터를 수집하지 않습니다. 무료 유지를 위해 광고는 계속 표시되지만, 비개인화 광고로 전환됩니다;
  • 동의·거부 모두 스크립트 녹화와 실행에 영향을 주지 않으며, 본 앱의 모든 기기 기능은 계속 사용할 수 있습니다.

「비개인화 광고」에 대하여: 광고를 요청하고 표시할 때 광고 SDK 는 기기·네트워크·광고 식별자 등의 정보를 Google 에 전송하여 광고 전달, 빈도 제어, 귀속 및 부정 행위 방지에 사용합니다. 이 정보는 사용자의 관심 프로필을 만들거나 개인화 타기팅에 사용되지 않습니다. 「비개인화」는 광고의 타기팅 방식을 제한하는 것이지, 데이터가 완전히 0 이라는 의미가 아닙니다.

유럽 경제 지역(EEA) 및 영국 사용자: Google 이 제공하는 표준 동의 화면(User Messaging Platform, UMP)이 추가로 표시됩니다. 해당 화면에서의 선택이 위 체크박스보다 우선하며, 광고 개인화 여부와 통계 활성화 여부를 직접 결정합니다. 해당 화면 또는 시스템 설정에서 언제든지 변경할 수 있습니다.

2. 수집하는 정보와 용도

2.1 스크립트 데이터: 기기에만 보관

플로팅 창에서 지정한 탭/스와이프 위치, 좌표, 시간, 지연, 반복 횟수, 그리고 사용자가 직접 입력한 스크립트 이름과 설명은 모두 기기 내 본 앱의 비공개 디렉터리에 기록되며, 업로드되지 않고 광고 타기팅의 근거로도 사용되지 않습니다. 앱 제거 시 함께 삭제됩니다.

2.2 광고 전달에 사용하는 정보(개인화 동의 여부와 관계없이 발생)

광고를 불러오고 전달하며 중복 제거·귀속·부정 행위 방지를 수행하기 위해, 광고 SDK(Google AdMob)는 다음 정보를 처리합니다:

  • 기기 및 앱 정보: 기기 모델, 브랜드, OS 버전, 화면 해상도와 픽셀 밀도, 앱 버전, 언어 및 지역;
  • 네트워크 정보: 네트워크 유형(Wi‑Fi / 이동 통신), IP 로부터 도출한 대략적인 지역(완전한 IP 는 저장하지 않음);
  • 광고 식별자: 광고 전달과 귀속에 사용하는 기기의 광고 식별자(GAID). 시스템 설정에서 재설정 또는 끌 수 있습니다.

동의 시 Google 이 위 정보를 개인화 타기팅에 사용할 수 있고, 거부 시 광고는 비개인화 방식으로 전달됩니다(「1」 참조). 광고 내용은 사용자의 스크립트 내용이나 좌표를 읽지 않습니다.

2.3 통계 및 크래시 조사에 사용하는 정보(동의 후에만 수집)

「1」에 따라 동의 선택을 한 후(EEA/영국 사용자는 UMP 에서 분석에 동의한 후)에만 본 앱은 Google Firebase Analytics 를 활성화하며 다음을 수집합니다:

  • 사용 정보: 기능 탭 횟수, 스크립트 실행 성공/실패 결과 코드 등의 이벤트;
  • 진단 정보: 안정성 조사를 위한 크래시 스택과 발생 위치.

거부 시 Firebase 는 초기화되지 않으며, 위의 사용 및 크래시 데이터는 단 한 바이트도 기기를 벗어나지 않습니다.

3. 접근성 권한: 왜 필요한가, 그리고 무엇을 하지 않는가

본 앱은 자동 탭과 스와이프를 구현하기 위해 시스템 「접근성 서비스」 권한이 필요합니다——이것은 이러한 자동화 도구가 클릭을 구현하는 일반적인 방식입니다. 이 권한에 대해 다음을 알아 주세요:

  • 사용자가 시스템 설정에서 직접 켜며 같은 곳에서 언제든지 끌 수 있습니다. 끄면 본 앱은 모든 자동화 능력을 즉시 상실합니다;
  • 본 앱은 이 권한을 사용자가 직접 만든 스크립트 실행에만 사용하며, 백그라운드에서 다른 앱의 화면 내용을 임의로 탐색·기록·업로드하지 않습니다;
  • 다른 앱에서 입력한 비밀번호, 결제 정보 등 민감한 내용을 본 앱은 인식하지 않고 기록하지 않으며 업로드하지 않습니다.

권장: 결제, 은행, 본인 인증과 관련된 페이지에서 자동화 스크립트를 실행하지 마세요. 스크립트 좌표는 기기에 저장되므로, 기기를 공유하거나 백업할 때 그 안에 포함될 수 있는 정보에 주의하세요.
