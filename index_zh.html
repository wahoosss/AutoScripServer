隐私协议

生效日期：2026 年 9 月｜适用产品：AutoScrip（本应用）｜本应用需要联网

本应用是一款在本机运行界面自动化脚本的工具软件，采用免费 + 广告的运营方式： 应用会联网加载广告并上报必要的运行诊断信息。请在使用前完整阅读本协议，你继续使用本应用即表示你接受本协议。

一、我们收集哪些信息，用于什么

1.1 脚本数据：只留在本机

你在悬浮窗里标记的点击/滑动位置、坐标、时长、延时、循环次数，以及你自己填写的脚本名称与描述， 都写在你设备的应用私有目录里，不会上传，也不会作为广告定向的依据。卸载应用即随之删除。

1.2 为保障联网与广告功能而收集的必要信息

为了加载广告、统计功能可用性与排查崩溃，我们会收集下列信息：

  • 设备与应用信息：设备型号、品牌、操作系统版本、屏幕分辨率与像素密度、应用版本号、语言与地区；
  • 网络信息：网络类型（Wi‑Fi / 蜂窝）、粗略的 IP 所属地区（不保存完整 IP）；
  • 广告标识：用于广告投放与归因的设备广告标识符，你可以在系统设置中重置或关闭它；
  • 使用与诊断信息：功能点击次数、脚本执行成功/失败的结果码、崩溃堆栈与发生位置。

上述信息不包含你的通讯录、短信、通话记录、相册、精确地理位置，也不会包含你在其它应用里输入的密码或支付信息。

1.3 广告

本应用展示的广告由第三方广告平台提供与投放。为实现广告的去重、归因与反作弊， 广告 SDK 会按其自身隐私政策使用上述 1.2 中的设备与网络信息。广告内容不读取你的脚本内容与坐标。

1.4 第三方 SDK 的公示方式

本应用接入的每一个广告、统计类第三方 SDK，都会在本页列出它的名称、收集范围与官方隐私政策链接后才随版本上线； 没有在本页出现的第三方，不在本应用中运行。清单更新会随应用版本一并发布。

二、无障碍权限与它能看到的内容

本应用需要系统的「无障碍服务」权限才能读取界面控件文字、并在你指定的位置执行点击与滑动。该权限：

  • 由你在系统设置里主动开启，你也可以随时在同一处关闭；关闭后本应用立即失去全部自动化能力；
  • 本应用只用它完成你亲自编排的脚本，不会在后台自行遍历、记录或上传其它应用的界面内容；
  • 你在其它应用里输入的密码、支付信息等敏感内容，本应用不做识别、不做记录、不做上传。

建议：不要在涉及支付、银行、身份验证的页面运行自动化脚本；脚本坐标会保存在本机， 分享或备份手机时请注意其中可能包含的信息。

三、信息的存储、共享与保护

  • 存储地点与期限：本机数据存在应用私有目录；联网上报的诊断与统计数据在服务端的最长保留期为 12 个月，到期删除或匿名化；
  • 传输安全：所有网络请求使用 HTTPS，广告与统计请求不携带你的脚本内容；
  • 共享范围：仅在实现广告、统计、故障排查所必需的范围内与第三方共享，不会出售你的个人信息； 在法律法规要求或主管部门强制要求时，我们可能依法提供，并在允许范围内通知你；
  • 跨境传输：若某项第三方服务涉及境外传输，会在接入时于本页单独说明并取得你的同意。

四、你的控制

  • 在应用内删除单个脚本，或「设置 → 应用 → 存储 → 清除数据」一次性清空本机数据；
  • 随时在系统设置里关闭无障碍权限；
  • 在系统设置中重置或关闭设备广告标识，可关闭个性化广告（仍会看到广告，只是不再基于兴趣）；
  • 在系统「应用管理」里禁止本应用联网，会导致广告无法加载、运行数据无法上报，但本机的脚本与执行不受影响。

五、未成年人使用

本应用面向成年用户。若你在未成年人设备上使用，请在监护人知情并同意的前提下进行； 我们不会针对未成年人做个性化广告投放。

六、协议更新

功能或数据处理方式发生变化时，我们会更新本页面并在应用内展示最新版本。 涉及新增数据收集、新增第三方或变更用途的，我们会在生效前显著提示。

本应用提供以下能力：在你手机上录制并保存一组操作脚本（点击坐标、点击控件文字、滑动、Home 键、Back 键）， 并按你编排的顺序与延时自动执行这些操作。本应用不代你执行任何你未编排的操作， 也不提供内容、交易或代运营服务。
