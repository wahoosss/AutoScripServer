プライバシーポリシー

施行日：2026 年 9 月｜対象製品：Auto Touch（本アプリ）｜本アプリはネットワーク接続が必要です

Auto Touch はデバイス上で動作する UI 自動化ツールです。無料かつ広告による収益化を前提に提供されています： アプリは広告の読み込みと、アプリの正常な稼働維持に不可欠な最小限の診断情報の報告のためにネットワークに接続します。 使用前に必ず本ポリシーをお読みください。本アプリを引き続きご使用された場合は、本ポリシーに同意したものとみなされます。

1. 収集する情報とその目的

1.1 スクリプトデータ：デバイス内にのみ保存

あなたが記録したタップ・スワイプの位置、座標、所要時間、開始遅延、ループ回数、および自分で入力したスクリプト名と 説明は、デバイスのアプリ専用領域に書き込まれます。これらは一切アップロードされず、 広告のターゲティングに使用されることもありません。アプリをアンインストールすると削除されます。

1.2 広告配信とアプリの稼働に必要な情報

広告の読み込み、機能の稼働状況の把握、クラッシュの調査のため、次の情報を収集します：

  • デバイスとアプリの情報：機種、ブランド、OS バージョン、画面解像度と密度、アプリバージョン、言語と地域；
  • ネットワーク情報：接続種別（Wi-Fi / モバイルデータ）、IP アドレスから導出したおおよその地域（完全な IP は保存しません）；
  • 広告識別子：広告の配信と帰属分析に使用するデバイス広告識別子。システム設定でリセットまたは無効化ができます；
  • 使用状況と診断情報：機能の利用頻度、スクリプト実行の成功／失敗結果コード、クラッシュスタックとその発生箇所。

上記に、あなたの連絡先、SMS、通話履歴、写真ライブラリ、正確な位置情報は含まれません。他のアプリで入力した パスワードや決済情報も一切含まれません。

1.3 広告

アプリに表示される広告は第三者の広告プラットフォームが提供・配信するものです。頻度制御、帰属分析、 不正対策を実現するため、広告 SDK は上記 1.2 のデバイス・ネットワーク情報を同社独自のプライバシーポリシーに 従って処理します。広告コンテンツがあなたのスクリプトや座標を読み取ることはありません。

1.4 第三者 SDK の開示方法

本アプリが統合するすべての広告・分析系第三者 SDK について、その名称、データの範囲、公式プライバシーポリシーへの リンクを本ページに掲載してからリリースします。本ページに掲載のない第三者は本アプリ内で動作していません。 リストの更新はアプリのバージョンとともに公開されます。

2. アクセシビリティ権限とその見え方

Auto Touch は、ウィジェットのテキストを読み取り、あなたが設定した位置でタップやスワイプを実行するために、 システムのアクセシビリティサービスの権限を必要とします。この権限について：

  • あなた自身がシステム設定で付与し、同じ場所でいつでも取り消せます。オフにするとすべての自動化が直ちに停止します；
  • あなた自身が作成したスクリプトの実行にのみ使用され、アプリが他アプリの内容を独自に閲覧・記録・アップロードすることはありません；
  • 他のアプリで入力したパスワードや決済情報などの機微コンテンツの認識・記録・アップロードには使用しません。

推奨：決済、銀行、本人確認に関わる画面で自動化を実行しないでください。 スクリプトの座標はデバイス内に保存されます——デバイスの共有や復元の際はその点にご留意ください。

3. 保存、共有、保護

  • 保存場所と期間：デバイス内のデータはアプリ専用領域に保存されます。ネットワーク経由で報告されたデータはサーバー側で最長 12 か月保持され、その後削除または匿名化されます；
  • 通信の安全：すべてのネットワーク要求は HTTPS を使用し、広告・診断の要求にスクリプトの内容を含めません；
  • 共有の範囲：広告、分析、障害調査に必要な範囲でのみ第三者と共有し、個人情報を売却しません。法令による要請がある場合はこれに従って開示することがあり、許される範囲であなたに通知します；
  • 越境移転：第三者サービスが域外移転を伴う場合、統合時に本ページで個別に明示し、同意をいただきます。

4. あなたの管理手段

  • アプリ内で個別のスクリプトを削除、または「設定 → アプリ → ストレージ → データ削除」でローカルデータを一括消去；
  • システム設定でアクセシビリティ権限をいつでも取り消し；
  • デバイス広告識別子をリセットまたは無効化して興味ベースの広告をオプトアウト（広告は表示され続けますが、パーソナライズされません）；
  • システム設定で本アプリのネットワークアクセスを遮断すると、広告の読み込みと診断報告は停止しますが、ローカルのスクリプトは動き続けます。

5. 未成年者

本アプリは成人ユーザーを対象としています。未成年者が使用する場合は、保護者の把握と同意のもとでご利用ください。 私たちは未成年者を対象としたパーソナライズド広告を配信しません。

6. 本ポリシーの変更

機能やデータの取り扱いが変更された場合、本ページを更新し、アプリ内で最新版を表示します。 データ収集の追加、第三者の追加、目的の変更を伴うものは、発効前に目立つ形でお知らせします。

7. お問い合わせ

本ポリシーに関するご質問、または照会・訂正・削除などの権利の行使は、開発者宛に wallehu99@gmail.com へメールでご連絡ください。その際、アプリのバージョン番号 （「設定 → バージョン情報」でご確認いただけます）を記載してください。

Auto Touch はデバイス上の UI 自動化を実行するツールです。無料かつ広告による収益化を 前提に提供されており、機能を完全に利用するにはネットワーク接続が必要です。本アプリのダウンロード、インストール、 または使用をもって、あなたは本規約を読み、同意したものとみなされます。

1. アプリの機能

本アプリはスマートフォン上での一連の操作——座標タップ、ウィジェットテキストによるタップ、スワイプ、ホーム、 バック——を記録・保存し、あなたが設定した順序と遅延で再生します。あなたが設定していない操作を執行することは一切なく、 コンテンツ、取引、運用代行なども提供しません。

すべての機能が無料です。課金も定期購読も、有料解放も一切ありません。 アプリ内で「課金でスクリプト解放」「実行を加速」等を謳う表示を見かけた場合、それは広告の誤導的な内容です——信じないでください。

2. ネットワーク使用と広告

  • 無料運用を維持するため、本アプリは広告を表示します。広告は第三者の広告プラットフォームが提供・配信するものです；
  • 広告の読み込みと実行診断の報告にはネットワーク接続が必要です。収集情報の正確な範囲は本ページのプライバシーポリシーをご覧ください；
  • システム設定でデバイス広告識別子をリセットまたは無効化すればパーソナライズを軽減できます。システム設定で本アプリのネットワークアクセスを遮断すると広告は読み込まれませんが、ローカルのスクリプトは使用できます；

  • 誤導的な広告をクリックして課金したり何かをダウンロードしたりしないでください——本アプリにそうした課金機構は存在しません。
